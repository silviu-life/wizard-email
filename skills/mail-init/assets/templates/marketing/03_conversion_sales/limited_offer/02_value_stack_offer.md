**Placeholder-uri pentru AI**:
- `[Prenume]`: First name (ton: excited to share value)
- `[oferta/produsul]`: What you're selling (ton: clear offering)
- `[deadline]`: When offer ends (ton: specific urgency)
- `[Produs/serviciu principal]`: Core offering (ton: main value)
- `[Valoare]`: Price/value (ton: quantified worth)
- `[Beneficiu principal]`: Main outcome (ton: transformation promise)
- `[Nume bonus]`: Bonus name (ton: desirable additions)
- `[Ce face/De ce e valoros]`: Bonus description (ton: standalone value)
- `[Special descriptor]`: What makes it special (ton: exclusive, rare)
- `[Suma bonuses + produs]`: Total value (ton: stack perception)
- `[Preț special]`: Actual price (ton: contrast with total value)
- `[diferență]`: Savings amount (ton: quantified discount)
- `[dată specifică + oră]`: Exact deadline (ton: precise urgency)
- `[CTA button]`: Action button text (ton: claim value)
- `[Garantie]`: Risk reversal (ton: safety net)
- `[Detalii garanție]`: Terms (ton: no-risk assurance)
- `[Numele tău]`: Your name (ton: generous giver)
- `[number]` locuri: Scarcity element (ton: limited availability)
- `[bonus specific valoros]`: Most desired bonus (ton: FOMO driver)

**Note de personalizare**:
- Value stacking = perceived value >> actual price
- Bonuses must have REAL value (not fake inflation)
- Each bonus needs clear description of value
- Specific deadline with exact time = urgency
- Guarantee reduces purchase anxiety
- Visual formatting (checkmarks, gifts) = scannable
- Can include: total value calculation, savings percentage
- P.S. reinforces urgency with specific scarcity
- Works best when bonuses genuinely complement core offer
- Follow with: countdown emails, last chance reminder
- Track: which bonuses drive most conversions
