# Value Add - Tool/Resource Recommendation

---

**Subiect**: [Subiect helpful: "[Number] tools for [use case]" sau "This [tool] saved me [hours/money]" sau "Resource recommendation: [topic]"]

---

Salut [Prenume],

Zero pitch azi - doar un tool/resource care cred că te-ar ajuta.

## [Tool/Resource name]

**Ce face**: [Descriere scurtă - 1-2 propoziții]

**De ce îmi place**: [Personal experience sau specific benefit - authentic]

**Perfect pentru**: [Use case specific relevant pentru audience-ul tău]

**Cost**: [Free/Paid/Freemium - transparent]

[Link către tool] ← Check it out

## Bonus recommendations

• [Tool/resource #2] - [Use case scurt]
• [Tool/resource #3] - [Use case scurt]

Nici unul dintre acestea nu îmi dă comision - recomand pentru că sunt utile.

[Numele tău]

P.S. - Ce tools folosești tu pentru [relevant task]? Reply - aș vrea să știu.

---

**Placeholder-uri pentru AI**:
- `[Prenume]`: First name (ton: helpful friend)
- `[Number]`: How many tools (ton: curated list - 1-5)
- `[use case]`: What tools help with (ton: specific need)
- `[tool]`: Specific tool (ton: time/money saved)
- `[Tool/Resource name]`: Main recommendation (ton: clear what it is)
- `[Descriere scurtă]`: What it does (ton: simple explanation)
- `[Personal experience]`: Your usage (ton: authentic endorsement)
- `[specific benefit]`: Why it's good (ton: concrete value)
- `[Use case specific]`: Who it's for (ton: relevant to audience)
- `[Free/Paid/Freemium]`: Pricing (ton: full transparency)
- `[Link către tool]`: Direct link (ton: easy access)
- `[Tool/resource #2-3]`: Additional recommendations (ton: bonus value)
- `[Use case scurt]`: Quick description (ton: digestible)
- `[Numele tău]`: Your name (ton: curator)
- `[relevant task]`: Their challenge area (ton: invite reciprocity)

**Note de personalizare**:
- Zero pitch = builds trust and goodwill
- Personal experience = authentic recommendation, not affiliate spam
- Transparency about cost/commission = credibility
- Can be: software tools, books, courses, templates, frameworks
- "No commission" statement = removes skepticism
- Bonus recommendations = overdeliver value
- P.S. invitation to share = engagement + learn from audience
- Works well between pitch emails to reset goodwill
- Can include: video demo, screenshots, your personal workflow
- Follow with: more value content or check if they found it useful
