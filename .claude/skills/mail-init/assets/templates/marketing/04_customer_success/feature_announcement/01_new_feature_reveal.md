# Feature Announcement - New Feature Reveal

---

**Subiect**: [Subiect benefit-driven: "New: [Beneficiu realizabil]" sau "[Feature name] is here!" sau "You asked, we built: [Feature]"]

---

Salut [Nume client]! 🎉

Avem ceva nou pentru tine în [produs].

## Meet [Nume feature]

[Descriere one-liner - ce face în termeni simpli - 1 propoziție benefit-focused]

## De ce contează pentru tine

[Problema pe care o rezolvă - 2-3 propoziții despre pain point sau limitation anterioară]

**Înainte:** [Cum era procesul înainte - poate inconvenient sau limitat]
**Acum:** [Cum e cu noul feature - mai rapid, mai ușor, mai powerful]

**Pas 1:** [Acțiune simplă - navigare către feature]
**Pas 2:** [Acțiune de setup/activare - simplu]
**Pas 3:** [Folosire - quick action]

[Link tutorial video sau GIF demo - vizual helpful]

## Rezultat

[Beneficiu concret - ce poți face acum care nu puteai înainte - cu timeframe/metric dacă e relevant]

• [Use case #1 - specific example]

• [Use case #3 - specific example]

**Placeholder-uri pentru AI**:
- `[Nume client]`: Prenume (ton: sharing excitement cu user)
- `[produs]`: Product name (ton: familiar)
- `[Nume feature]`: Feature name (ton: branded, memorable)
- `[Descriere one-liner]`: What it does (ton: clear benefit, not technical jargon)
- `[Problema pe care o rezolvă]`: Pain point addressed (ton: "we heard you")
- `[Cum era procesul înainte]`: Old way (ton: acknowledge limitation)
- `[Cum e cu noul feature]`: New way (ton: improvement highlight)
- `[Acțiune simplă]` step 1-3: How to use (ton: easy instructions, anyone can do it)
- `[Link tutorial]`: Help resource (ton: visual guide)
- `[Beneficiu concret]`: Outcome specific (ton: practical impact)
- `[Use case #1-3]`: Real applications (ton: spark ideas)
- `[CTA]`: Action button (ton: try it now)
- `[Link direct]`: Deep link to feature (ton: zero friction)
- `[Link knowledge base]`: Detailed docs (ton: comprehensive resource)
- `[Numele tău]`: Prenume (ton: builder sharing work)
- `[Titlul]`: Role (ton: team member)
- `[Fun fact]` sau `[roadmap teaser]`: P.S. engage (ton: community-built, future peek)

**Note de personalizare**:
- Focus pe USER BENEFIT, nu feature specs
- Before/After contrast = shows improvement clearly
- Simple how-to = remove adoption barrier
- Visual demo = video/GIF > text explanation
- Use cases = help users see applicability
- Deep link to feature = activate immediately
- Solicit feedback = show you care about experience
- Can include: "You asked for this" if user-requested
- Roadmap teaser = maintain engagement
